# Audit ME Project V3 · 24 November 2026

Baseline GitHub `30352579c37792c754452656289243e7e064a3d1`, PR #18. Inventaris GitHub menunjukkan 19 branch dan 18 PR sebelum pekerjaan ini, dengan `main` di `479836835`. Pohon baseline lengkap meliputi Android, backend Node referensi, dua workflow dan dokumentasi. Backend punya 55 tes yang lulus secara lokal dan tidak dipaketkan di Android. Android menggunakan Kotlin 2.2.21, AGP 8.13, Gradle 8.13 di CI, JDK 17, SDK 26–36, OkHttp 5.4.0, JUnit 4.13.2 dan Robolectric 4.15.1. Versi dependency diperiksa dari konfigurasi. Audit ini tidak menyertifikasi seluruh dependency transitif bebas kerentanan.

Status di bawah merupakan status **baseline**, sehingga temuan tetap dapat ditelusuri setelah perbaikan. COMPLETE berlaku untuk lingkup sempit pada baris tersebut. Kolom uji membedakan fixture, uji logika, dan bukti perangkat. Nama berkas Android mengacu ke paket `com.mefuturesaibot.app` beserta subpaketnya.
